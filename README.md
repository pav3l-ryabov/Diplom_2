## Дипломный проект. Задание 2: API-тесты

### Автотесты для проверки работы с юзерами и заказами в Stellar Burgers

### Структура проекта

- `data.data.py` - хранит константы
- 
- `methods.order_methods.py` - хранит методы для работы с заказами
- `methods.user_methods.py` - хранит методы для работы с юзерами
- 
- `tests.conftest.py` - хранит фикстуру, создающую, а затем удаляющую юзера
- `tests.create_order.py` - хранит тесты, проверяющие эндпоинты создания заказа
- `tests.create_user.py` - хранит тесты, проверяющие эндпоинты создания юзера
- `tests.get_order.py` - хранит тесты, проверяющие эндпоинты получения заказа
- `tests.login_user.py` - хранит тесты, проверяющие эндпоинты авторизации юзера
- `tests.patch_user.py` - хранит тесты, проверяющие эндпоинты изменение информации о юзере
- 
- `credentials_generator` - хранит метод, генерирующий учетные данные

### Запуск автотестов

> `$ pytest --alluredir=reports`

**Установка зависимостей**

> `$ pip install -r requirements.txt`
